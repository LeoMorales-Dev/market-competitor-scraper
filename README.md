# Market Competitor Scraper 🚗📊

## 📋 Descripción
Herramienta de automatización de alto rendimiento diseñada para la extracción masiva de tarifas competitivas en el sector Car Rental. Este script permite recolectar datos estratégicos de múltiples locaciones (Cancún, CDMX, Monterrey, etc.) para alimentar modelos de **Pricing Dinámico** y análisis de paridad de mercado.

## 🚀 Características Técnicas
- **Robustez:** Implementación de esperas explícitas y manejo de excepciones para navegación en sitios dinámicos.
- **Eficiencia:** Automatización de procesos de búsqueda y descarga que reducen el trabajo manual en un 90%.
- **Seguridad:** Gestión de credenciales mediante variables de entorno para proteger el acceso a portales corporativos.
- **Escalabilidad:** Arquitectura preparada para iterar sobre diversos mercados (México/USA) y duraciones de renta.

## 🛠️ Tech Stack
- **Lenguaje:** Python 3.x
- **Librerías:** Selenium WebDriver, Webdriver-manager.
- **Entorno:** Manejo de variables de sistema (`os`, `dotenv`).

## 📈 Impacto en el Negocio
Desarrollado originalmente para optimizar la toma de decisiones en **AVASA**, este script asegura que el equipo de Revenue Management cuente con información actualizada de la competencia en tiempo real, facilitando ajustes de tarifa inmediatos para maximizar el RevPAR.
